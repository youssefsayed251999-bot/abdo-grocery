# خطوات ربط Supabase — بقالة عم عبده

الهدف: تتحفظ بيانات المتجر (منتجات، أسعار، طلبات، محادثات، إشعارات، إعدادات) على Supabase وتفضل موجودة على النت.

---

## 1) اعمل مشروع جديد

1. ادخل <https://supabase.com> واضغط **Start your project** (ممكن تدخل بحساب GitHub أو Google).
2. اضغط **New project**.
3. اكتب:
   - **Name**: `abdo-grocery`
   - **Database Password**: أي باسورد قوي (واحفظه)
   - **Region**: اختار أقرب منطقة (مثلاً `Europe` أو `Middle East`).
4. اضغط **Create new project** واستنى دقيقة لحد ما يخلّص.

---

## 2) اعمل الجداول

1. من القائمة الجانبية: **SQL Editor** ← **New query**.
2. افتح ملف `supabase/schema.sql` من المشروع، وانسخ **كل** محتواه.
3. الصقه في المربع واضغط **Run** (لازم يطلع `Success`).

> الخطوة دي بتعمل كل الجداول وتقفلها بـ RLS (يعني محدش يوصلها غير السيرفر).

---

## 3) هات المفاتيح

من **Project Settings** ← **API**:

| اللي تنسخه | تحطه في `server/.env` |
|---|---|
| **Project URL** (زي `https://xxxx.supabase.co`) | `SUPABASE_URL=...` |
| **secret key** (يبدأ بـ `sb_secret_...`) | `SUPABASE_SERVICE_KEY=...` |

> الملف موجود في المشروع: `server/.env`
> (لو مش موجود، انسخ `server/.env.example` باسم `.env`).

---

## 4) اتأكد إن الاتصال تمام

```bash
node tools/supabase_check.js
```

المفروض يطلع:

```
🎉 الاتصال تمام والجداول موجودة!
```

لو قال **«الجدول مش موجود»** → ارجع للخطوة 2 وشغّل `schema.sql`.
لو قال **«المفتاح مرفوض»** → اتأكد إنك ناسخ مفتاح **secret** مش الـ publishable.

---

## 5) شغّل السيرفر

```bash
node server/server.js
```

لازم يطبع:

```
  قاعدة البيانات: Supabase ☁️
```

أول تشغيل هيزرع الأقسام والمنتجات والإعدادات تلقائيًا. 🎉

---

## تعديل الأسعار والصور

من الموقع (وأنت مالك، كلمة السر `admin123`):
**لوحة التحكم ← 🛒 المنتجات ← تعديل** → غيّر السعر/الصورة → **حفظ**.

أو مباشرة من **Supabase ← Table Editor ← products**.

---

## ملاحظات أمان

- المفتاح اللي يبدأ بـ `sb_secret_` **سري جدًا** — سيبه في `server/.env` بس.
- `server/.env` **مستثنى من البناء** (`node tools/build.js`) فمش بيتوزّع مع الموقع.
- لو حصل إن المفتاح اتكشف، من **Settings ← API** اضغط **Rotate** وحدّث `server/.env`.
