# 🛒 بقالة عم عبده — موقع متجر إلكتروني متكامل (PWA)

موقع متجر بقالة مصري كامل، مبني بـ **HTML + CSS + JavaScript** فقط، ويعمل كـ **تطبيق PWA** يتثبّت على الموبايل والكمبيوتر ويعمل أوفلاين.

معاه **سيرفر Node.js بسيط (بدون أي مكتبات خارجية)** يخلي **الرسائل والطلبات حقيقية فعلًا بين أجهزة مختلفة**: العميل يبعت من موبايله، وصاحب المحل يرد ويتابع من جهاز تاني، لحظيًا. ومن غير السيرفر الموقع يشتغل عادي جدًا بالبيانات المحلية.

مستوحى من فكرة الفيديو: متجر + لوحة تحكم للمالك + نظام رسائل وإشعارات + تتبع طلبات + PWA.

## ✨ المميزات

### واجهة العميل (المتجر)
- 🏠 **الرئيسية**: بانر عروض، الأقسام، خصومات، الأكثر مبيعًا، منتجاتنا، شريط ثقة.
- 🛒 **المنتجات**: بحث فوري، فرز (الأكثر مبيعًا / الأرخص / الأغلى / الأعلى تقييمًا)، فلترة بالأقسام.
- 🔍 **صفحة المنتج**: الوصف، المواصفات، التقييم، الكمية، أضف للسلة / اشترِ الآن، منتجات مشابهة — **بصور حقيقية**.
- 🛒 **السلة**: تعديل الكميات، الحذف، ملخص الطلب، حد أدنى للطلب، توصيل مجاني عند حد معيّن.
- 💵 **إتمام الطلب**: الاسم، الموبايل، العنوان، المنطقة، ملاحظات، طريقة الدفع (**الدفع عند الاستلام** فقط).
- 🧾 **صفحة الطلب**: رقم الطلب، خط زمني للحالة، ملخص المنتجات، الإجمالي.
- 📦 **تتبع الطلبات**: ابحث برقم الموبايل وشوف كل طلباتك وحالتها.
- 💬 **الرسائل**: **محادثة حقيقية** بينك وبين المحل (لكل عميل محادثة خاصة) — بتتزامن لحظيًا لو السيرفر شغّال.
- 🔔 **الإشعارات**: صندوق إشعارات (عروض، تأكيد الطلب، تغيّر حالته…) — الوارد من المحل بيظهر على كل الأجهزة.
- 👤 **حسابي**: تسجيل دخول / إنشاء حساب، تعديل الملف الشخصي، بياناتي، طلباتي.

### لوحة تحكم المالك (تظهر فقط لصاحب المتجر)
- 📊 **نظرة عامة**: مؤشرات (طلبات اليوم، الإيرادات، صافي الربح، الطلبات المعلّقة، المخزون المنخفض…).
- 🧾 **الطلبات**: فلترة بالحالة/البحث، تغيير الحالة، تفاصيل الطلب، طباعة فاتورة.
- 🛒 **المنتجات**: إضافة/تعديل/حذف، المخزون، سعر التكلفة، الخصم، المواصفات، **صورة (رفع/رابط) أو إيموجي**.
- 💬 **الرسائل**: كل محادثة عميل على حدة + ردود سريعة جاهزة — **ترد فعليًا على العميل من أي جهاز**.
- 🔔 **الإشعارات**: قوالب جاهزة، معاينة مباشرة، اختيار الجمهور، إرسال لكل العملاء.
- 📈 **الإحصائيات**: الإيرادات، صافي الربح، متوسط قيمة الطلب، الأكثر/الأقل مبيعًا، حسب المنطقة، طرق الدفع، معدل الإلغاء، مخطط مبيعات يومي.
- ⚙️ **الإعدادات**: اسم المتجر والشعار، التوصيل (رسوم / مجاني بعد / حد أدنى / **المنطقة: إنشاص الرمل**)، إعدادات الإشعارات، تصدير/استيراد/تصفير البيانات.

### تقني
- 📲 **PWA**: تثبيت بضغطة واحدة، أيقونة، splash، **يعمل أوفلاين** عبر Service Worker.
- 🌐 **RTL عربي** كامل + خط Cairo. 📱 تصميم متجاوب (موبايل/تابلت/كمبيوتر).
- 💵 **الدفع**: الدفع عند الاستلام فقط (اتشال الدفع الإلكتروني والمحفظة نهائيًا).
- 📍 **منطقة التوصيل**: **إنشاص الرمل** (قابلة لإضافة مناطق تانية من لوحة التحكم).

## 🧩 نسختان: للمطوّر وللمستخدم

عشان يبقى عندك نسخة تجريبية تشتغل عليها ونسخة نظيفة تدّيها للعملاء، المشروع فيه سكربت بناء:

```bash
node tools/build.js
```

بينتج مجلدين جاهزين للاستخدام مباشرة:

| النسخة | الوضع | الفرق |
|---|---|---|
| `dist/dev` | مطوّر | **بيانات تجريبية** (طلبات ومحادثة جاهزة) + **أدوات مطوّر** (زرار 🐞: بيانات تجريبية/تصدير/استيراد/تصفير) |
| `dist/user` | مستخدم | **نظيفة** — بدون أي بيانات وهمية، بدون أدوات مطوّر. دي اللي تدّيها للعملاء |

> كل نسخة **مستقلة تمامًا** وفيها السيرفر جواها. عايز تبني من الأول بعد أي تعديل؟ شغّل `node tools/build.js` تاني.

## 🚀 التشغيل

### 1) تشغيل كامل (موصى به) — رسائل وطلبات حقيقية
شغّل السيرفر (بدون أي `npm install` — صفر مكتبات):

```bash
node server/server.js
```

هو بيخدم **الموقع + الـ API معًا** على نفس المنفذ:

```
http://localhost:8080
```

افتح الرابط من أي جهاز على نفس الشبكة (استخدم IP الجهاز بدل `localhost`) هتلاقي الرسائل والطلبات بتتزامن لحظيًا. وكل البيانات بتتحفظ في **Supabase** (أو في `server/data.json` لو مفيهاش مفاتيح Supabase).

خيارات:
```bash
node server/server.js --port 3000            # تغيير المنفذ
node server/server.js --root dist\user       # خدمة نسخة معينة
node server/server.js --data my-data.json    # ملف بيانات مخصص
node server/server.js --supabase-url URL --supabase-key KEY   # مفاتيح Supabase مباشرة
```

> **للمشاركة على الإنترنت:** ترفعه على استضافة مجانية زي **Render** أو **Railway** — اختر "Web Service"، أمر التشغيل `node server/server.js`، وهو هيستخدم `PORT` تلقائيًا.

### 2) تشغيل الموقع فقط (بدون سيرفر — بيانات محلية)
الموقع يشتغل لوحده كملفات ثابتة (الرسائل تبقى على نفس الجهاز بس):

```bash
python -m http.server 8080
# أو
npx serve .
```

> مهم: افتح الموقع عبر سيرفر محلي (http) وليس بالنقر المباشر على الملف، لكي يعمل التثبيت والعمل أوفلاين. على ويندوز شغّل `serve.bat` (أو `serve.ps1`).

## 🗄️ ربط Supabase (قاعدة بيانات حقيقية على الإنترنت)

البيانات (المنتجات، الأسعار، الطلبات، المحادثات، الإشعارات، الإعدادات) تتحفظ على **Supabase**، وتفضل موجودة حتى لو أعدت تشغيل السيرفر أو غيّرت الجهاز.

**الخطوات (مرة واحدة):**

1. اعمل مشروع مجاني على <https://supabase.com>.
2. من القائمة الجانبية: **SQL Editor → New query**، والصق محتوى ملف `supabase/schema.sql` كله واضغط **Run**.
3. من **Project Settings → API** انسخ:
   - **Project URL**
   - **service_role key** (المفتاح السري — مش anon)
4. في المشروع، انسخ ملف `server/.env.example` باسم `server/.env` واملأه:
   ```
   SUPABASE_URL=https://xxxxxxxx.supabase.co
   SUPABASE_SERVICE_KEY=eyJhbGciOi...
   ```
5. شغّل السيرفر: `node server/server.js` — هيقولك **«قاعدة البيانات: Supabase ☁️»**.

> أول تشغيل بيملأ القاعدة تلقائيًا بالأقسام والمنتجات والإعدادات الجاهزة.
> لو المفاتيح مش موجودة، السيرفر يشتغل عادي بالبيانات المحلية (`server/data.json`).

**أمان:** الجداول عليها **RLS مقفول**، يعني محدش يوصلها غير السيرفر (بمفتاح الخدمة). الموقع نفسه بيكلم السيرفر بس.

## 🖼️ تعديل الصور والأسعار (من غير أي كود)

1. افتح الموقع وأنت داخل كـ **مالك** (كلمة سر `admin123`).
2. **لوحة التحكم ← 🛒 المنتجات**.
3. اضغط **تعديل** على أي منتج وغيّر:
   - **السعر** (وسعر الخصم / نسبة الخصم / المخزون).
   - **الصورة**: ارفع صورة من جهازك أو حطّ رابط صورة.
4. اضغط **حفظ** — التغيير يتحفظ في Supabase ويظهر لكل الزوار فورًا.

> تقدر كمان تعدّل الأسعار/الصور مباشرة من **Supabase → Table Editor → products** لو حبيت.

## 🔐 الدخول للوحة التحكم

1. من الموقع: صفحة **حسابي** ← زر **«🔐 دخول المالك — لوحة التحكم»**.
2. كلمة المرور الافتراضية: **`admin123`**.
3. غيّرها من: **لوحة التحكم ← الإعدادات ← كلمة مرور لوحة التحكم**.

> زر «لوحة التحكم» في الشريط العلوي يظهر **فقط** بعد الدخول كمالك.
> لو السيرفر شغّال، كلمة السر بتتحقق من السيرفر والتوكن بيفضل معاك بعد إعادة التحميل.

## 🖼️ الصور الحقيقية

كل المنتجات جاهزة بصور حقيقية حرة الترخيص تم تنزيلها محليًا (تشتغل أوفلاين).
لو عايز تحدّث الصور أو تجيب صور تانية:

```bash
node tools/fetch_images.js
```

بيجيب صور من **Wikimedia Commons** ويعمل fallback على **Openverse**، ويربطهم بالمنتجات. أي منتج يفشل يفضل بالإيموجي تلقائيًا، وتقدر تحطّ صور كاملة من **لوحة التحكم ← المنتجات**.

## 🔧 ملاحظات مهمة

- **بدون السيرفر:** البيانات (طلبات/رسائل/إشعارات) تُخزَّن في `localStorage` على نفس الجهاز.
- **مع السيرفر:** كل حاجة بتتزامن فعليًا بين كل الأجهزة لحظيًا عبر Server-Sent Events، والبيانات تُحفظ في **Supabase** (أو في `server/data.json` لو مفيهاش مفاتيح Supabase).
- **الدفع:** الدفع عند الاستلام فقط.
- **إشعارات النظام (Push):** إشعارات الموقع تعمل بدون سيرفر. الوصول وأنت خارج الموقع يحتاج Push حقيقي عبر سيرفر (VAPID) — الجاهزية موجودة في `sw.js` (حدث `notificationclick`).
- **الأسعار والتوصيل والمناطق:** كلها قابلة للتعديل من لوحة التحكم ← الإعدادات.
